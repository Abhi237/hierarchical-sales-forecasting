# Data

**Dataset:** M5 Forecasting (Accuracy), Walmart US store sales published for the M5 competition (organised by the Makridakis Open
Forecasting Center, University of Nicosia, hosted on Kaggle). 3,049 items, 3 categories, 7 departments, 10 stores in 3 states
(CA 4 stores, TX 3, WI 3), calendar with events and SNAP days, weekly sell prices.

**Citation:** Makridakis, Spiliotis and Assimakopoulos (2022), "M5 accuracy competition: Results, findings, and conclusions",
International Journal of Forecasting 38(4).

**Licence: no standalone open licence found.** The data originate from the Kaggle competition and fall under its rules, which are
described in secondary sources as non-commercial use, academic research and education. I could not retrieve the rule text itself, so
check the competition rules before any commercial use. For that reason the raw files are **never committed**: `data/raw/` is
git-ignored, only derived aggregates are published (`tableau/data/`, `artifacts/`), and `scripts/download_data.py` fetches the
files. The only committed input is a synthetic M5-format fixture (`tests/fixtures/m5_mini/`, generated by `tests/make_fixture.py`,
invented numbers, 60 series).

## Fetch (no credentials needed)

```bash
make data          # = python scripts/download_data.py
python scripts/download_data.py --from-dir /path/with/the/three/csvs
```

**Date correction to the brief:** the 1,941 sales days run from 2011-01-29 (d_1) to **2016-05-22** (d_1941), not to 2016-06-19. The
calendar continues to 2016-06-19 (d_1969); those last 28 days are the competition's hidden evaluation period and are not in the
sales file used here. Weekly modelling uses the 277 complete Saturday-to-Friday weeks (2011-01-29 to 2016-05-20); the 2 trailing
days are dropped and logged.
